# 斜梁版 · E2.320 试用 PR

三角形自动次梁：进入「梁布置 → SB」，选择 X／Y／自动及最大间距（m）。整层处理可选「全部区域」；局部处理先「框选 SB 区域」，框到三角形内部即可选取所属完整主梁／墙梁格，再「预览次梁 → 应用布置」。例如 6 × 6 m 三角形、X 向及最大间距 3 m，会在中间布置一根横向 SB，连接斜边主梁和右侧边梁。区域方向和间距可在下方分区表修改，再预览应用。

次梁按独立主梁／墙梁格布置，最大间距按支承参考中心线控制；分区显示实际多边形，保存重开保留布置与手动梁。旧版误判的三角形分区可重新预览；支承或梁格改变时按提示重画。Slab 页支持实际三角形／多边形点选、框选和高亮，方向仍统一在 Slab 选择。没有柱／墙支承路径时，画出次梁仍会显示待确认，不代表构件验算通过。

可先在「梁布置」直接画斜梁，不需要启用斜边范围。画梁本身不裁切建筑范围。需要斜边外轮廓时，在「区域」展开「斜梁版 · 斜边与三角形板」，沿边输入凸多边形顶点（X, Y，m），或点选轴线交点后应用。原建筑范围、Opening 和删除板区仍有效。当前斜边轮廓支持 3–64 个凸多边形顶点；不要用交叉折线表达凹口，凹口仍由原建筑格及 Opening 表达。

在「梁布置」选 MB / SB / TB / CB，点两端支承画梁。斜梁沿实际方向绘制和选取，跨度沿梁自身量取。SB 可接到斜梁；自动 SB 在接触斜梁的独立主梁／墙梁格内生成，原有保存布置和手动梁保留。缺少支承、重叠或多重承托仍需处理。

板始终按 one-way slab。选择 X 或 Y 受力方向，验算采用该方向各受支承条带中的最长跨度，并使用原有单向板公式、选筋及 Excel 输入。不是直接把斜边长度当作板跨度。指定跨度不得短于自动最大值。多个荷载区的板验算采用各项面荷载的最大值作为均布包络，界面标明；传荷仍按各荷载区实际范围。实际板厚、面荷载、配筋及挠度限制仍可能使验算不通过。

向梁传荷使用实际板净面积，扣除梁、墙、柱及洞口占地。每条单向简支条带按合力及其位置求两端反力，映射到支承梁的实际站位；变化区段用自适应分段线性荷载表示，并检查总荷载守恒。梁自重仍按完整截面，梁顶 SDL/LL 单独分配一次。柱荷载继续采用独立的几何受荷面积归属。

App 梁反力、M/V 及短期弹性挠度支持渐变荷载。给原 Excel 的输入在控制截面处分段，采用保持合力和一阶矩的两段均布荷载；保留原 Excel 的核对和不一致阻断。总荷载、支反力及控制 ULS M/V 对应原始荷载；Excel 内两控制截面间的曲线是等效分段表示。此输入适配不修改原 Excel/VBA 或 Section A/B 抄的版式及公式。

没有斜梁或多边形区域的原矩形模型保持原计算路径；同一斜边模型内几何没有改变的矩形板继续使用原有板计算。新节点的抗扭、整体连续刚度与连接设计未由简支条带模型推断。保存项目使用原「保存项目」，撤销仍有效。

「几何与出图」的预览、SVG 和打印按实际多边形表示斜梁、板边和无板区，板标记放在实际板内部。出图位置调整继续只影响图纸，计算和 Section A/B 抄不受影响。

基于正式 E2.316，作为独立试用 PR，不自动合并 main。PR #24 的 E2.317 页面内确认及 Windows EXE 工作流仍独立。
