# E2.319 離線柱位方案助手

在「06 柱」展開「柱位方案助手 · 離線預覽」。這是 EXE 內建的有限候選搜尋，不需要網絡或 AI。

1. 先在「03 柱 SPACING」按題目輸入 X／Y 最小柱中心距，在「04 區域」完成樓面、Opening 及禁柱區。
2. 在「06 柱」設定新增柱的預設 B／D，然後打開方案助手。目標 X／Y 柱距控制候選密度；不能放寬 03 的最小限制。
3. 如題目另有限制，可輸入最大 X／Y 中心距。此數字只檢查同行／列及既有同軸柱的相鄰中心距，不是實際梁跨度或支承驗算。
4. 按「產生柱位方案」。助手比較現有柱、建築軸網、均勻及較疏候選，優先上下層中心對齊，再比較樓面抽樣距柱／牆距離和柱數，最多列出三個可套用方案。
5. 先看預覽與限制，再按「套用」。綠色為新增、藍色為保留、紅叉為將移除的未鎖定自動柱。套用同步共用 Framing，可一次撤銷。

手動柱、已有尺寸／位置／構件輸入／選取／Foundation 指定的柱、接梁柱及已套用的方案柱保持固定。現有建築軸線不會被新增柱改寫。新柱按完整截面避開 Opening、禁柱區、牆及樓面外；既有固定柱若有衝突，顯示原因而不忽略它。

套用前會在副本核對柱位、截面、間距、參考柱及每條既有梁的位置／尺寸。會改變既有梁的候選不列為可套用方案。模型或方案設定變更後須重新搜尋。正常刪柱同時記錄其實際截面，方案助手不在該範圍自動補回；舊版未曾記錄的自由柱刪除歷史無法追溯。

第一版適合在未布梁的方案初期使用。已完成梁布置的模型可能只有「保留現有柱位」；不會為了產生不同方案而改動既有梁。現有 HKIE 2025 Q5 模型 F03 的 24 支柱均已固定，因此保留原柱；排除四個會改變既有梁或無法完整套用的候選。

這是幾何方案建議，不表示已完成 RC、梁跨度、樓面承托、轉換結構或穩定系統設計。搜尋有候選數上限；沒有候選不等於已證明無解。選定方案後仍按題目檢查布梁、傳荷及結構設計。

## 回到 E2.318

另行解壓保存的 E2.318 Windows 套件，使用其中的 FramingStudio.exe 開啟修改前備份模型。保留兩個獨立版本資料夾，不要用新套件覆蓋舊資料夾。E2.319 新欄位屬額外方案／刪除保留資料；需要完全回到原狀時，使用 E2.318 隨附的修改前模型備份。
