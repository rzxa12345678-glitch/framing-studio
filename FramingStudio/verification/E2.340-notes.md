# E2.340 — preserve adjacent column positions and simplify scheme cards

Local successor of accepted E2.338 (0213b89); E2.339 remains cancelled and no
trial code was used. GitHub publication is on explicit user hold.

The assistant previously preferred a replacement local grid when the floor below
had no columns, even when upper columns were available. It now offers a candidate
that retains legal adjacent physical centres: common upper/lower centres first,
then lower support centres, then upper centres. Existing protected columns remain
fixed. Full section, wall clearance, disabled-column, spacing and all shared-floor
checks still apply. Conflicts are counted; unresolved support stays explicit.
The regular infill alternative starts with these accepted centres instead of
moving them to a new grid. Short-span TB alternatives remain available.

Scheme cards show actions at the top, column/alignment counts and support review
status. Detailed geometry, routes and search diagnostics are collapsed initially.
Disclosure restoration uses search/card identities so an old expanded coordinate
list cannot open a different new card after a search.
