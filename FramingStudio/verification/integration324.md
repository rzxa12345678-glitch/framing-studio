# E2.324 · 斜梁版：整合 PR #24 / #26 / #27 / #28

以 E2.320 的三角形次梁、点选区域及 Slab 方向处理为基础，合入 #28（含 #27 的完整 CAD 框选历史）与 #24。通过实际 merge 保留四个 PR 的提交，不以某一版本的整份文件覆盖另一分支。

## 功能核对

- #26：直接斜梁绘制、区域原模式与点选、保留斜边坐标输入、方向统一在 Slab、三角形 SB 逐主梁／墙梁格布置、保存重开、手动及删除记录。
- #27：左→右完整框入、右→左相交选取，按斜梁／板实际多边形选取；保留 CAD 框选及点选区域各自的 Esc 取消。
- #28：各楼层上墙自动跟随下墙实际偏移，手动位置优先，梁端及支承更新；Summary Check 筛选、表格与按钮样式。
- #24：离线柱位候选、明确预览／应用／撤销，最小中心距、手动及删除记录保护；梁尺寸更新反馈；页内确认；原生保存／关闭响应；区域填色与 3D 板体独立。

## 整合缺陷修复

1. 排柱方案以完整柱截面和实际楼面多边形作差，识别斜边、点选 Opening、内部孔洞与不连续范围。角点／中心在内不再代表整个截面有效。9×9 m 三角形中原来漏报的 0.32 m² 柱截面越界会拒绝，恰好贴边可保留。
2. 搜索候选和最终应用均核对共用 Framing 的各层实际墙位，任何一层不一致整批拒绝，项目不被部分改写。
3. 上墙跟随偏移若越出点选／斜边建筑范围，保留原墙并明确提示；修复整合前墙被裁掉而没有对应边界提示的情况。

72 组计算／浏览器回归通过，另执行 11 组最终针对性复测（已包含于 72 组去重计数）。原有矩形板、SB/TB 审核输出、反力守恒、柱面积路线、三角形 SB、CAD 框选、轴线插入、复制墙柱、报告滚动／缩放、Summary 13 组合及保存重开均纳入。

实际编译 Windows EXE 在独立 WebView2 配置中通过 65 项确认、取消、原生保存、关闭响应、柱方案、撤销重开及显示检查。使用合成模型，不包含用户私人项目；24 根固定柱样例并非当前用户工程。最初沙箱会话渲染器无法启动，改在用户 Windows 会话的隔离测试目录完成。重复运行使用新配置，避免测试备份被当作新输入。
