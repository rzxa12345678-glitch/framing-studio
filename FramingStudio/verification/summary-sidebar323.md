## 修正範圍

- 組合表補上既有側欄表格容器，恢復表框、表頭、圓角及列互動樣式；窄側欄可換行，表格不超出容器。

- 更新全樓 Check 使用既有 primary 主按鈕類別。原事件、文字、停用狀態及 App-only 檢查流程保留。
- 新增容器後，批次建議的捲動查詢排除組合表，維持對原結果表的處理。
- 新 CSS 僅在 screen、普通 UI scope、`#side .summary-issues131` 內生效；不作用於 A/B 報表、報表對話框及列印。
